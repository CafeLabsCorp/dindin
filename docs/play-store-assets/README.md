# Play Store listing graphics

Graphics uploaded to the Dindin store listing on Google Play (see `../PLAY_CONSOLE.md`, "Store listing"). The PNGs are not versioned: they live on disk and on Drive (`gdrive:dindin`).

- `icone-512.png` — app icon, 512×512. Current version (2026-11-12): the bag with the **D coin** (brand manual v1.1) on the dark background `#16130F`, the same as the app's adaptive icon.
- `grafico-destaque-1024x500.png` — feature graphic, 1024×500. Current version (2026-11-12): dark background `#16130F`, "Dindin" in Fraunces SemiBold (`#F5F1EA`), the line "Seu dinheiro em caixinhas." in green `#7FCB9E` and the bag on the right. The line is not defined in the brand manual.
- `capturas/01.png` … `06.png` — the 6 phone screenshots, in listing order
- `anteriores/` — the first listing graphics (2026-09-24, old logo), kept for reference.

`#16130F` is the official dark background (decided 2026-11-12; the brand manual was corrected to match). Use it for any new store art.
